# Data

`download_data.py` downloads the standard AG News train and test CSV files to `data/raw/`. Both files are checksum-verified. Raw data are excluded from Git; the downloader provides a reproducible retrieval path.

AG News is assembled from the AG corpus for research purposes, described by the source as non-commercial activity. This project documents the source and does not redistribute the corpus. Review the original dataset terms before any commercial use.
