# Data

`download_data.py` retrieves the UCI Student Performance archive into `data/raw/`. The archive is intentionally excluded from Git; the downloader is the reproducible source of the data.

This project uses the Mathematics records (`student-mat.csv`) and predicts `G3`. The UCI dataset is licensed CC BY 4.0. Cite Paulo Cortez, *Student Performance*, UCI Machine Learning Repository, DOI: 10.24432/C5TG7T, and retain the dataset attribution when redistributing any data-derived work.
