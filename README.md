# Machine Learning Portfolio Projects

Three independent, beginner-friendly Python and scikit-learn projects, each with a Streamlit app, reproducible training pipeline, evaluation scripts, tests, and project-specific documentation.

## Projects

1. [Student Performance Prediction](student-performance-prediction/)
2. [Language Identification](language-identification/)
3. [News Article Classification](news-article-classification/)

Each project has its own `requirements.txt`, virtual environment, dataset downloader, model artifacts, evaluation results, and launch instructions. Raw datasets and trained binary models are kept local; use the documented commands in each project to retrieve data and rebuild models.
