# Data

`download_data.py` fetches the original WiLI-2018 archive from Zenodo into `data/raw/` and extracts the four official train/test text and label files (`x_train.txt`, `y_train.txt`, `x_test.txt`, and `y_test.txt`). The 62.4 MB archive and extracted data are excluded from Git.

WiLI-2018 is published under the Open Database License (ODbL). Cite Martin Thoma, “The WiLI benchmark dataset for written language identification,” and the Zenodo record DOI 10.5281/zenodo.841984. See the project README for source links and attribution details.
